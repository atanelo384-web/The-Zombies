# The Zombies 4.2

Изометрическая пиксельная игра на выживание в бесконечном мире. Днём вы обыскиваете города и заправки,
рубите лес, чините брошенные машины и собираете команду. Ночью к базе приходит орда. Играть можно одному
или с друзьями по локальной сети.

## Что нового в 4.2 — кланы

- **Кланы в мультиплеере.** Клан создаётся клавишей `K` или через F3 → «Клан». Нужны название и один из 10 цветов.
- **Приглашения.** В списке игроков (F3) рядом с игроками без клана есть кнопка «В клан». Приглашённому придёт окно «Вступить / Отказаться».
- **Настройки клана** меняет глава:
  - название и цвет;
  - **PvP**: если выключено, участники не ранят других игроков и сами неуязвимы для них;
  - **метки соклановцев** на мини-карте и карте мира, только настоящие игроки, без ботов.
- **Управление.** Глава может исключать участников, передавать главенство и распускать клан. Остальные могут выйти сами.
- **Свои не ранят друг друга** никогда.
- **Название клана** в цвете клана видно в чате рядом с ником, над головой игрока (у своих со звёздочкой) и в списке игроков.
- **Клановый чат**: `/c текст`.
- Чужие игроки без клана видны на мини-карте только рядом с вами (до 26 клеток), а на карте мира — только соклановцы.
- Кланы хранятся в мире хоста и сохраняются вместе с ним. В клане до 16 игроков.

Когда запас кончается, они обыскивают холодильники, шкафы и кусты рядом, пьют из воды и сборников, подбирают еду с земли и берут нужное из ящиков базы. Лишние находки отдают вам. В панели команды видны полоски еды и воды и то, чем напарник занят.
- **Интерфейс:** новые ячейки инвентаря с цветом по типу предмета, полоса веса, карточки подсказок, панель быстрого доступа с подсветкой, полосы здоровья и крафт.

## Как запустить

**В браузере:** откройте `index.html` в Chrome, Edge или Safari. Мультиплеер в браузере работает между вкладками: откройте игру во второй вкладке, создайте второй аккаунт и подключитесь.

**На телефоне (Android / iPhone):** подробности в `mobile/README.md`.
- **Android:** установите `dist/TheZombies.apk` (на телефоне разрешите установку из этого источника).
- Проще всего — открыть ссылку с ПК, на котором запущен сервер.
- Можно собрать настоящее приложение: APK для Android или IPA для iPhone.

**Как настоящую игру (окно, сохранения в файлах, сетевая игра):**
1. Установите Node.js LTS с https://nodejs.org.
2. Дважды щёлкните `Запустить игру.bat`. При первом запуске скачаются зависимости (около 200 МБ). Это нужно сделать один раз.

## Голосовой чат

- Работает в мультиплеере автоматически: в версии для ПК (`Запустить игру.bat`), в приложениях для Android и iPhone и в браузере по `https` или `localhost`.
- Если телефон открыл игру по обычной ссылке `http://IP-ПК:27015`, браузер запрещает доступ к микрофону. Такой игрок **слышит** всех, но говорить может только из приложения.
- В локальной сети звук идёт напрямую между устройствами. Через интернет голос обычно тоже работает (используется STUN), но за строгими NAT может не соединиться.

## Мультиплеер по сети

1. Хост: «Мультиплеер», затем «Запустить сервер». Выберите мир, число игроков и PvP.
2. **Телефоны (Android, iPhone)** в той же Wi-Fi сети сканируют QR-код из Esc → «Пригласить друзей» или открывают ссылку `http://IP-ПК:27015` в браузере. Затем «Играть на этом сервере».
3. **Друзья на ПК** в той же сети: «Мультиплеер», затем «Обновить список». Сервер появится сам.
4. **Выделенный сервер без игры:** `Запустить сервер.bat` (Windows) или `./start-server.sh` (Mac / Linux / Raspberry Pi / VPS). Хостом становится первый, кто создаст на нём мир, — даже с телефона.
5. Через интернет:
   - Либо откройте у хоста TCP-порт 27015 на роутере.
   - Либо используйте Radmin VPN или Hamachi.
   - Затем подключайтесь по IP хоста (кнопка «Пригласить» в меню паузы покажет адрес).
6. Если Windows спросит про доступ к сети для The Zombies, разрешите его.

Мир, постройки и машины хранятся у хоста. Персонажи гостей (вещи, здоровье, позиция) сохраняются в мире хоста под их аккаунтом.

## Сборка .exe для Steam

Дважды щёлкните `Собрать для Steam.bat` или выполните `npm run dist`.

- `release/*.exe` — установщик.

## Как выпустить в Steam

1. Зарегистрируйтесь в Steamworks (partner.steamgames.com) и оплатите Steam Direct (100 $ за игру). Получите App ID.
2. Впишите App ID в `steam/steam_appid.txt` вместо `480`.
3. В Steamworks создайте достижения с такими ID (заглавными буквами):
   `PILOT SAILOR HOMEBUILDER DIGGER MECHANIC2 FIRST_BLOOD KILLS100 KILLS1000 KILLS5000 NIGHT1 NIGHT5 NIGHT15 NIGHT30 HARD5 BUILDER ARCHITECT TEAM3 TEAM10 DRIVER TRUCKER MECHANIC BOOMER BOSS BRUTES SOLDIERS EVAC POLAR TRAVELER EXPLORER HUNTER BEAR SNIPER MELEE PYRO TEAMPLAY DUELIST COOK FISHER DOGFRIEND FOREMAN DAILY7 POCKET CROSSPLAY LUMBER`
4. Выполните `npm install`. `steamworks.js` и `ws` установятся сами. Затем соберите игру.
5. Загрузите `release/win-unpacked` через SteamPipe (ContentBuilder из Steamworks SDK). Исполняемый файл — `The Zombies.exe`.
6. Подготовьте страницу магазина: капсулы, скриншоты, трейлер. Промпты для картинок лежат в `PROMPTS_ChatGPT.md`.
7. Установите цену и отправьте игру на проверку.
