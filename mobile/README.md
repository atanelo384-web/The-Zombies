# The Zombies на телефоне (Android и iPhone)

Есть три способа играть на телефоне. Все три работают и на Android, и на iPhone, и везде можно играть вместе с ПК.

## 1. Без установки — через браузер (проще всего)
1. На ПК запустите игру и нажмите «Мультиплеер → Запустить сервер». Без игры можно запустить `Запустить сервер.bat`.
2. Нажмите Esc → «Пригласить друзей». Появятся QR-код и адрес вида `http://192.168.1.5:27015`.
3. На телефоне в той же Wi-Fi сети отсканируйте QR-код камерой или откройте адрес в Safari или Chrome.
4. Нажмите «Играть на этом сервере».

Чтобы игра открывалась на весь экран, как приложение:
- **iPhone:** «Поделиться» → «На экран Домой».
- **Android:** меню ⋮ → «Добавить на главный экран».

## 2. Приложение для Android (.apk)
**Готовый файл:** `dist/TheZombies.apk` в архиве с игрой (Android 7.0 и новее). Скопируйте его на телефон и откройте. Android попросит разрешить установку из этого источника. При первом запуске разрешите микрофон, если хотите говорить в голосовом чате.

**Пересобрать этот APK после изменений в игре:** `python3 mobile/apk-lite/build_apk.py`. Понадобятся aapt2, android.jar, smali и пакет npm `apk_sign_ts`, подробности в начале скрипта. Подпись лежит в `mobile/apk-lite/keys/`. Сохраните её: обновления APK должны быть подписаны тем же ключом, иначе Android не даст обновить приложение поверх старого.

**Вариант А: в облаке, без установки программ**
1. Загрузите папку проекта в свой репозиторий на GitHub.
2. Откройте вкладку **Actions**, выберите **Build phone apps** и нажмите **Run workflow**.
3. Через 5–10 минут скачайте `TheZombies-android.apk` из раздела Artifacts.
4. Откройте файл на телефоне. Android попросит разрешить установку из этого источника.

**Вариант Б: на своём ПК**
1. Установите Android Studio и Node.js.
2. В папке `mobile` выполните `npm install`, затем `npm run android`.
3. В Android Studio выберите Build → Build APK.

## 3. Приложение для iPhone (.ipa)
- **Без Mac:** GitHub Actions (как в п. 2А) соберёт `TheZombies-unsigned.ipa`. Установите его через Sideloadly или AltStore со своим Apple ID. С бесплатным Apple ID приложение нужно переподписывать раз в 7 дней — это ограничение Apple.
- **С Mac:** установите Xcode. В папке `mobile` выполните `npm install`, затем `npm run ios`. В Xcode выберите свою команду (Signing) и нажмите ▶ с подключённым iPhone.
- **В App Store:** нужен аккаунт Apple Developer (99 $ в год), затем Xcode → Product → Archive.

## Важно
- Телефон и ПК должны быть в одной Wi-Fi сети. Через интернет нужен открытый порт 27015 на роутере хоста или VPN вроде Radmin VPN, ZeroTier или Tailscale.
- Аккаунт переносится между устройствами: Профиль → Аккаунты → «Показать код» на одном устройстве и «Загрузить из кода» на другом.
- После изменения игры в корневой папке выполните `npm run sync`, чтобы обновить приложения.
